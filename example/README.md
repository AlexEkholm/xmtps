# Example files

Real files from one dive: float 9303, dive 440 (2026-08-27). The dive was sent as 12 SBD messages,
MOMSN 5803 to 5814. Each folder holds one kind of file, in the order the pipeline produces them:

| Folder | Production location | Produced by | Contents |
|---|---|---|---|
| [`mail/`](mail/) | IMAP inbox; the full text is also kept in the database (`XFloatMail.msg_raw_text`) | Iridium gateway | The notification email for MOMSN 5814 (packet 0, the last one sent): a text part with the session details and the SBD message as a base64 attachment. |
| [`sbd/`](sbd/) | `<dir.sbd>/incoming/<serial>/<serial>-<MOMSN>-<dive>.sbd` | decoder | The 12 SBD attachments as binary files: X-message packets (`X nn mm dd p <blobs> $cc>`, see [the X-message specification](../spec/xmessage-format.md)). |
| [`raw/`](raw/) | `<dir.raw>/<serial>/raw<serial>-<MOMSN>-<dive>-<packet>.txt` | decoder | One RAW file per message: the processing details, mail header, Iridium session details and the SBD data as hex. |
| [`listing/`](listing/) | `<dir.lis>/<serial>/lis<serial>-<dive>.txt` | decoder | The dive's listing file, decoded from all 12 messages (see [Listing files](../README.md#listing-files)). |
| [`json/`](json/) | `/data1/alamo/data/json/<serial>/` | `xmtps-list2json.py`, `xmtps-aggregate-json.py` | The per-dive file [`dives/9303_0440.json`](json/dives/9303_0440.json), the aggregate GPS file [`9303_gps.json`](json/9303_gps.json) and the float summary [`9303_summary.json`](json/9303_summary.json) (see [JSON files](../README.md#json-files)). |
| [`plots/`](plots/) | `/data1/alamo/data/plots2/<serial>/` | `xmtps-aggregate-json.py` | The temperature profile plot at its three sizes ([full](plots/9303_profile_temp.png), [small](plots/9303_profile_temp_small.png), [thumbnail](plots/9303_profile_temp_thumb.png)), and the position plot as an image ([PNG](plots/9303_position.png)) and as an interactive page ([HTML](plots/9303_position.html), which loads Plotly from its CDN). The plots cover all of 9303's dives up to 2026-10-26. |

The listing, JSON and plots are as regenerated by decoder 0.6.3310a on 2026-10-26.

## Changes from the production files

- **IMEI:** the float's IMEI is masked to its last 7 digits (`XXXXXXXX2418110`), as in listing
  files, in the RAW files and the email (subject and attachment name). Because of this, the email
  can't be decoded as is: the decoder takes the IMEI from the subject.
- **Email headers:** the email keeps only the headers written by the Iridium gateway (`Message-Id`,
  `Date`, `Reply-To`, `From`, `To`, `Subject`, `MIME-Version`, `Content-Type`). The relay headers
  added on the way to the inbox (`Received`, `Authentication-Results`, `ARC-*`, `X-MS-*` and
  others) are removed, since they name internal mail hosts and addresses. The body is unchanged.
- **Listing:** the "Iridium Position" section (the `IRI` line) is removed, as the decoder no
  longer writes it.

The SBD, JSON and plot files are unchanged.
